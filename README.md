# rudrapratapsinghjadon

Personal portfolio of Rudra Pratap Singh Jadon, AI Engineer.

## Run locally

```sh
npm run dev
```

Open http://127.0.0.1:4173.

## Build

```sh
npm run build
```

The build writes the production website to `dist/`. Node.js is required for the build. No npm dependencies are needed.

## Host on GitHub Pages

1. Open this repository's **Settings → Pages**.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select **main** and **/ (root)**, then save.

The root directory contains the website and its assets. The `.nojekyll` file serves it as a static site.

The default project URL is https://rudrajadon.github.io/rudrapratapsinghjadon/.

To use a custom domain, configure it in **Settings → Pages → Custom domain** and add the DNS records shown by GitHub.

## Edit the portfolio

- `index.html` contains the page content.
- `styles.css` contains the layout, colors, and animations.
- `main.js` contains the menu and page interactions.
- `assets/` contains photos, fonts, and the downloadable resume.

Push changes to `main` to update the GitHub Pages website after Pages is enabled.
